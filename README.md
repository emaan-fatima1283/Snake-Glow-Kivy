# 🐍 Snake Glow Kivy

A modern, glow-themed mobile arcade game built using **Python** and the **Kivy** cross-platform framework. Designed with a sleek neon aesthetic, smooth touch controls, and optimized for Android devices.

---

## ✨ Features
* **Neon Glow Aesthetics:** High-contrast glowing visual elements for an immersive arcade experience.
* **Cross-Platform Architecture:** Built in Python, deployable as a native mobile application via Kivy and Buildozer.
* **Smooth Controls:** Responsive touch-based directional controls optimized for mobile touchscreens.
* **Dynamic Scoring:** Real-time score tracking and progressive speed mechanics.

---

## 🛠️ Tech Stack
* **Language:** Python 🐍
* **Framework:** Kivy (UI & Game Loop Engine)
* **Deployment:** Buildozer / Android SDK
